# 0103 Premade bars for everyone, not only druid owners

## Why

Rob, 2026-10-14, on card `0099`: "we should work out a way to do this mapping for everyone (I would
like to get it working better for myself first though!)".

"Make premade bars from your druid's bars" needs a druid's saved bars as its template. Card `0099`
hides it from accounts with no druid for the first release. This card is the later fix: a way for
any player to get premade bars, whatever classes they play.

   a generated block, and someone's key choices become everyone's start.
